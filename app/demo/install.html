Put it on your printer.

For a Raspberry Pi printer that already runs Klipper and Moonraker. Mainsail or Fluidd stays where it is.

1 · On the printer, over SSH

$curl -fsSL https://bench.elyir.com/install | sh

It checks the printer first and asks once before it changes anything. About a minute.

2 · Scan the code it shows

Your phone opens the printer, ready to go. A computer can use the link shown beside the QR code instead.

Starting from a blank Raspberry Pi? Download the card for a Pi 4 or a Pi 5, flash it with Raspberry Pi Imager (Use custom, and No when it offers OS customization), then power the Pi on and join the Elyir Bench Wi-Fi it makes.

What it adds

Elyir Bench at your-printer.local:8088, and on the printer's screen if you say so.

Away from home, with a plan: an address of its own on Elyir's relay, like p-k7qx2mna.elyir.app, opens it from anywhere. It never carries your printer's name. Testers have it free.

An ACE Pro: Elyir Bench's own driver, with one include line in printer.cfg. If another driver already runs it, it asks first.

What it leaves alone

printer.cfg (apart from that one line) and your macros, Mainsail or Fluidd, your files and print history. KlipperScreen stays installed.

Changed your mind?

On the printer, elyir-bench remove takes it off and puts KlipperScreen back.

Needs a Raspberry Pi 4 or 5, a BTT Pi or a CB1, on a 64-bit system. Not during a print: it checks, and waits.

Will it work on my printer?

On every board below, Elyir Bench works on your phone and computer the same way. The differences are the screen and slicing.

BoardThe screenSlicing on the printerWhat you get

Not sure which you have? Run the command: it names your board and says what it will do before it changes anything. A printer that can't slice by itself prints files from your own slicer as always, and another printer running Elyir Bench on your Wi-Fi can slice for it.

Later on

Updating

Run the same command again. It sees Elyir Bench is already there, says the next step is an update, and asks before it changes anything.

A release that doesn't start properly is undone on the spot, back to the one before.

Taking it off

On the printer: elyir-bench remove. The screen goes back to KlipperScreen, and Elyir Bench's own files go.

printer.cfg goes back as it was; Mainsail, your files and history were never changed. elyir-bench.conf stays, in case you come back.
